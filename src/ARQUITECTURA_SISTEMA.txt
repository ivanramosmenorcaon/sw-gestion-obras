┌─────────────────────────────────────────────────────────────────────────────┐
│                       CICLO DE VIDA                                        │
└─────────────────────────────────────────────────────────────────────────────┘

1. BOOT (Laravel)
   ├─ Carga config/action-icons.php
   └─ Registro de commandos Artisan

2. REQUEST (Usuario)
   ├─ Abre relation manager en navegador
   └─ Filament renderiza la tabla

3. RENDER (Tabla)
   ├─ Lee recordActions()
   ├─ Para cada acción
   │  ├─ Llama $this->withActionIcons()
   │  ├─ Obtiene icono y tooltip del config
   │  ├─ Configura la acción
   │  └─ Renderiza acción con icono
   └─ Muestra tabla con iconos

4. INTERACCIÓN (Usuario)
   ├─ Pasa mouse sobre icono
   ├─ Ve tooltip
   ├─ Hace clic en acción
   └─ Se ejecuta la acción


┌─────────────────────────────────────────────────────────────────────────────┐
│                      PERSONALIZACIÓN                                       │
└─────────────────────────────────────────────────────────────────────────────┘

Opción 1: CAMBIAR ICONO DEL CONFIG
  config/action-icons.php
  └─ 'edit' -> 'icon': 'tabler-pencil' ✎ CAMBIA AQUÍ
     └─ Se aplica a TODAS las relation managers

Opción 2: SOBRESCRIBIR EN RELATION MANAGER
  $this->withActionIcons(EditAction::make(), 'edit')
       ->icon('tabler-custom-icon')  ✎ CAMBIA AQUÍ
  └─ Se aplica SOLO a esta relation manager

Opción 3: TOOLTIP DINÁMICO
  $this->withActionIcons(EditAction::make(), 'edit')
       ->tooltip(fn ($record) => "Editar {$record->name}")  ✎ DINÁMICO
