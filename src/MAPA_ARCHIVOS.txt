═══════════════════════════════════════════════════════════════════════════════════
                         CÓMO USAR CADA ARCHIVO
═══════════════════════════════════════════════════════════════════════════════════

PARA CONFIGURAR:
├── Edita: config/action-icons.php
└── Cambios se aplican automáticamente a todas las relation managers

PARA IMPLEMENTAR:
├── En relation manager:
│   ├── Agregar: use App\Filament\Traits\HasIconizedActions;
│   ├── Agregar trait: use HasIconizedActions;
│   └── Usar: $this->withActionIcons(Action::make(), 'action_name')
│
└── Ejecutar: vendor/bin/pint --dirty

PARA VER LEYENDA:
├── Agregar widget al panel:
│   └── ->widgets([ActionIconsLegendWidget::class])
│
└── Widget muestra todos los iconos con tooltips

PARA TESTEAR:
├── Ejecutar: php artisan test tests/Unit/ActionIconsHelperTest.php
└── Verificar que todos los tests pasen ✓

PARA APRENDER:
├── Comenzar: README_ICONOS.md
├── Guía: ICONOS_GUIA_PRACTICA.md
├── Técnica: ACCIONES_CON_ICONOS.md
├── Avanzado: EJEMPLOS_AVANZADOS_ICONOS.php
└── Diagramas: ARQUITECTURA_SISTEMA.txt
